آهنگ‌بان — اجرای داشبورد Brand Kit روی ویندوز

۱) فایل ahangban-brand-kit.zip را دانلود و Extract کنید.
۲) وارد پوشهٔ ahangban-brand-kit شوید.
۳) روی start-localhost.bat دوبار کلیک کنید؛ پنجرهٔ جداگانهٔ سرور باز می‌شود.
۴) مرورگر نشانی http://localhost:8000/hub.html را باز می‌کند.
۵) سازندهٔ پرامپت در http://localhost:8000/prompts.html در دسترس است.
۶) پنجرهٔ سرور را تا پایان کار باز نگه دارید؛ برای خاموش‌کردن، در همان پنجره Ctrl+C بزنید یا آن را ببندید.

پیش‌نیاز: Python 3 برای ویندوز. اسکریپت ابتدا لانچر py و سپس python را امتحان می‌کند. اجرای localhost به اینترنت نیاز ندارد.

اگر پورت ۸۰۰۰ اشغال بود، مقدار PORT داخل start-localhost.bat را عوض کنید.
برای داشبوردی که JSON محلی می‌خواند، به‌جای بازکردن hub.html با دوبارکلیک از همین سرور استفاده کنید.

برای استقرار عمومی، Python http.server را استفاده نکنید؛ فایل‌ها را در DocumentRoot وب‌سرور واقعی قرار دهید و TLS، firewall و دسترسی عمومی را جداگانه پیکربندی کنید. به‌خاطر داشته باشید فایل‌های JSON این بسته برای هر بازدیدکننده قابل دریافت هستند.
