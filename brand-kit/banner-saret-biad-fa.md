# بنر اسلایدر ویژهٔ «سرت بیاد» — مهدی جهانی

**نوع:** پس‌زمینهٔ افقی اسلایدر · **ابعاد:** ۶۴۰×۳۶۰ پیکسل (۱۶:۹) · **نسخهٔ ۲x:** ۱۲۸۰×۷۲۰
**وضعیت:** فقط پس‌زمینه؛ هیچ متن، حرف، عدد، لوگو یا واترمارک در تصویر نیست.

## فایل‌ها

| فایل | کاربرد |
|---|---|
| `assets/banner-saret-biad-640x360.png` | فایل اصلی اسلایدر، اندازهٔ دقیق ۶۴۰×۳۶۰ |
| `assets/banner-saret-biad-1280x720.png` | همان طرح برای نمایشگر ۲x و پوشش Retina |
| `assets/banner-saret-biad-640x360.webp` | نسخهٔ سبک وب (کیفیت ۹۲) |
| `tools/generate-banner-saret-biad.py` | سازندهٔ قابل‌اجرا؛ همهٔ هندسه در همین فایل مستند است |

هر دو خروجی PNG مستقیماً در اندازهٔ خودشان رندر می‌شوند (بدون بزرگ‌نمایی از ۱x) و هر دو با همان مختصات طراحی شده‌اند.

## ساختار بصری

- **یک‌سوم چپ (x: 0–213):** میدانِ یکدستِ `#111111` و کاملاً خالی؛ فقط برای کاور اصلی اثر.
- **دو سوم راست:** سطحِ زغالی `#222222` با یک ستون تحریریه‌ای: خط سرسطر، لبهٔ راست و خط پایه.
- **سفید کنترل‌شده:** فقط سه خط مویی در شفافیت ۰٫۰۹ تا ۰٫۱۵ — نه سطح سفید بزرگ.
- **تنها تأکید آبی:** نشانهٔ گوشهٔ بالا-راست در `#185ADB` خالص، به‌عنوان نقطهٔ شروع خواندن در RTL.
- **بدون** گرادینت، بافت تصویری، نماد کلیشه‌ای موسیقی، چهرهٔ ساختگی یا بافت شلوغ.

## توزیع رنگ در خروجی

| رنگ | نقش |
|---|---|
| `#111111` | یک‌سوم چپ، سطح پایه |
| `#222222` | پنل تحریریه‌ای دو سوم راست |
| `#FFFFFF` (شفافیت پایین) | خطوط مویی |
| `#185ADB` | فقط نشانهٔ گوشه؛ هیچ آبی دیگری در فایل نیست |

## منطقهٔ امن (در مقیاس ۶۴۰×۳۶۰)

```
کاور اصلی      x: 27–187   y: 100–260     مربع ۱۶۰×۱۶۰، وسط‌چین عمودی
ستون متن       x: 236–608  y: 48–300      شروع از راست، تراز راست
حاشیهٔ راست     ۳۲px        حاشیهٔ بالا/پایین ۳۰px
خط پایه        y: 330      زیر آن متن نگذارید
```

## چیدمان پیشنهادی متن RTL

متن فارسی بعداً در خود سایت روی بنر می‌نشیند؛ ترتیب از بالا به پایین:

1. نام هنرمند — «مهدی جهانی» — ۱۳px، وزن ۵۰۰، `#BDBDBD`
2. عنوان آهنگ — «سرت بیاد» — ۴۰px، وزن ۹۰۰، `#FFFFFF`
3. نوع اثر — ۱۲px، `#8C8C8C`
4. اقدام — دکمهٔ کپسولی آبی `#185ADB` با متن سفید، ارتفاع ۳۰px

```css
.hb-banner{position:relative;aspect-ratio:16/9;background:#111111;overflow:hidden;border-radius:16px}
.hb-banner__bg{position:absolute;inset:0;width:100%;height:100%;object-fit:cover}
.hb-banner__cover{position:absolute;inset-inline-start:4.22%;top:27.78%;width:25%;aspect-ratio:1;
  object-fit:cover;border-radius:2px}
.hb-banner__body{position:absolute;inset-inline-end:5%;top:13.3%;width:55%;
  text-align:start;color:#fff;font-family:"Ahangban Vazirmatn",Tahoma,Arial,sans-serif}
.hb-banner__artist{font-size:.8125rem;font-weight:500;color:#bdbdbd;margin:0 0 2px}
.hb-banner__title{font-size:clamp(1.35rem,1.375vw + 1rem,2.5rem);font-weight:900;line-height:1.25;margin:0}

```

> درصدها از همان نقاط امن بالا محاسبه شده‌اند؛ در عرض کوچک‌تر فقط اندازهٔ فونت با `clamp` تغییر می‌کند و هندسه ثابت می‌ماند.

## کنترل کیفیت

- [x] ابعاد دقیق ۶۴۰×۳۶۰ و نسبت ۱۶:۹.
- [x] بدون متن، حرف، عدد، لوگو یا واترمارک.
- [x] کاور بازتولید، تقلید یا دست‌کاری نشده؛ فقط فضای آن خالی است.
- [x] فقط چهار رنگ: `#111111`، `#222222`، سفید شفاف و `#185ADB`.
- [x] بدون گرادینت و بدون نماد کلیشه‌ای موسیقی.
- [x] فضای منفی کافی برای عنوان فارسی در چیدمان RTL.
- [x] خطوط مویی با آنتی‌آلیاس‌نشدن در ۱x بررسی شدند؛ هر دو خروجی تک‌به‌تک پیکسل‌محور رندر شده‌اند.
