پس‌زمینهٔ بنر اسلایدر ۶۴۰×۳۶۰ آهنگ‌بان با جای خالی کاور در یک‌سوم چپ و عنوان فارسی HTML در دو سوم راست.

== Description ==

این افزونه یک بنر آمادهٔ ۱۶:۹ (۶۴۰×۳۶۰ و نسخهٔ ۲x) را با شورت‌کد نمایش می‌دهد:

`[ahangban_banner href="/saret-biad" cover="https://example.com/cover.webp"]`

- تصویر پس‌زمینه همراه افزونه است؛ نیازی به آپلود جداگانه ندارد.
- عنوان، نام هنرمند، نوع اثر و دکمه به‌صورت متن واقعی رندر می‌شوند: قابل انتخاب، ترجمه و خوانده‌شدن با صفحه‌خوان.
- چیدمان از منطقهٔ امن طرح پیروی می‌کند: کاور ۴٫۲۲٪ چپ و ۲۷٫۷۸٪ بالا با عرض ۲۵٪؛ متن با فاصلهٔ ۵٪ از لبهٔ راست.
- پالت فقط `#111111`، `#222222`، سفید و `#185ADB`؛ بدون گرادینت.
- استایل تنها در صفحه‌ای بارگذاری می‌شود که شورت‌کد دارد.

== Installation ==

1. افزونه را در «افزونه‌ها ← افزودن ← بارگذاری افزونه» نصب و فعال کنید.
2. در ویرایشگر بلوک، الگوی «بنر ویژهٔ آهنگ — سرت بیاد» را از دستهٔ «آهنگ‌بان» درج کنید، یا یک بلوک «شورت‌کد» بسازید.
3. مقدار `href` و `cover` را با پیوند و کاور واقعی همان اثر جایگزین کنید.

== Frequently Asked Questions ==

= آیا کاور اثر داخل افزونه است؟ =
نه. کاور متعلق به صاحب اثر است و باید از کتابخانهٔ رسانهٔ خودتان داده شود؛ اگر خالی بماند، یک جای‌گیر با خط مویی نمایش داده می‌شود.

= آیا ارتفاع اسلایدر را می‌توان تغییر داد؟ =
نسبت تصویر باید ۱۶:۹ بماند. اگر قالب شما ارتفاع ثابت می‌دهد، آن را روی `aspect-ratio: 16/9` تنظیم کنید تا منطقهٔ امن متن و کاور به‌هم نریزد.

= چطور روی سایت چپ‌به‌راست استفاده کنم؟ =
کلاس `hb-banner--ltr` را اضافه کنید: `[ahangban_banner class="hb-banner--ltr"]`. تصویر آینه می‌شود و متن از چپ شروع می‌شود.
