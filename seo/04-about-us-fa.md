- در صفحهٔ هنرمند، لینک به وب‌سایت یا صفحهٔ رسمی هنرمند فقط با احراز رسمی‌بودن؛ انکر: «وب‌سایت رسمی [نام هنرمند]» با `rel="noopener"` و بازشدن در زبانهٔ تازه.
- در صفحهٔ اثر، برای واقعیت‌هایی مثل تاریخ انتشار یا سازندگان، اگر منبعی ذکر می‌شود همان منبع رسمی (ناشر/صفحهٔ رسمی هنرمند) لینک شود؛ از سایت‌های دانلود رقیب به‌عنوان «منبع» لینک داده نمی‌شود.
- لینک خارجی تبلیغاتی یا پولی روی هیچ صفحه‌ای بدون `rel="sponsored"` قرار نمی‌گیرد؛ در متن‌های تحریریه‌ای این بسته هیچ لینک پولی وجود ندارد.

## دادهٔ ساختاریافتهٔ نهایی این صفحه

```json
{
  "@context": "https://schema.org",
  "@graph": [
    {
      "@type": "AboutPage",
      "@id": "https://ahangban.ir/about/#webpage",
      "url": "https://ahangban.ir/about/",
      "name": "درباره آهنگ بان",
      "inLanguage": "fa-IR",
      "isPartOf": { "@id": "https://ahangban.ir/#website" },
      "about": { "@id": "https://ahangban.ir/#organization" },
      "mainEntity": { "@id": "https://ahangban.ir/#organization" }
    },
    {
      "@type": "Organization",
      "@id": "https://ahangban.ir/#organization",
      "name": "آهنگ بان",
      "alternateName": "AhangBan",
      "url": "https://ahangban.ir/",
      "slogan": "از پیدا کردن تا شنیدن.",
      "sameAs": [
        "https://t.me/ahangban_ir",
        "https://www.instagram.com/ahangban.ir/"
      ]
    },
    {
      "@type": "BreadcrumbList",
      "itemListElement": [
        { "@type": "ListItem", "position": 1, "name": "آهنگ بان", "item": "https://ahangban.ir/" },
        { "@type": "ListItem", "position": 2, "name": "درباره ما", "item": "https://ahangban.ir/about/" }
      ]
    }
  ]
}
```

قواعد این اسکیما:

- `sameAs` با دو پروفایل رسمی ثبت‌شده (تلگرام `@ahangban_ir` و اینستاگرام `@ahangban.ir`، به اعلام مالک برند در ۱۹ اکتبر ۲۰۲۶) تکمیل شده است؛ پروفایل پلتفرم‌های بعدی فقط بعد از ثبت واقعی به همین فهرست اضافه شود.
- `logo` فقط با URL واقعی لوگوی منتشرشده روی خود سایت؛ URL حدسی ساخته نشود.
- اگر بخش «پرسش‌های رایج» عیناً روی صفحه نمایش داده شد، می‌توانید برای همان سه پرسش `FAQPage` هم اضافه کنید؛ اگر نمایش داده نشد، اسکیمایش را نگذارید.
- هیچ `Review`، امتیاز، تاریخ تأسیس، تعداد کاربر یا نشانی پستی ساختگی وارد نشود.

### نکته اجرایی هنگام انتشار

- اگر دسته «آرشیو کامل خواننده‌ها» (`/full-archive/` یا نام نهایی آن) هنوز منتشر نشده است، در متن بالا به آن لینک ندهید؛ هر وقت صفحه‌اش زنده شد، یک جمله به پاراگراف «در آهنگ بان چه پیدا می‌کنید؟» اضافه کنید: «و در بخش آرشیو کامل خواننده‌ها، آثار هر خواننده را یکجا و دسته‌بندی‌شده می‌بینید.»
- شعار «از پیدا کردن تا شنیدن» در کتاب برند «پیش‌نویس» ثبت شده است؛ اگر تصمیم برند عوض شد، همان یک خط را اصلاح کنید.

## ساختار هدینگ

- H1: درباره آهنگ بان
- H2: در آهنگ بان چه پیدا می‌کنید؟
- H2: چطور کار می‌کنیم؟
- H2: برای هنرمندان و صاحبان اثر
- H2: از کجا شروع کنید؟ (پاراگراف پایانی با لینک به `/music/` و `/artists/`)

## لینک‌سازی داخلی

- **داخل متن (مقصدها):** آهنگ‌های جدید `/music/`، آلبوم‌ها `/album/`، ریمیکس `/remix/`، موزیک‌ویدئو `/music-video/`، مداحی `/madahi/`، هنرمندان `/artists/`، تماس با ما `/contact/`.
- **به این صفحه:** فوتر همه صفحات (انکر: «درباره ما»)، صفحه تماس، و صفحه اصلی از بخش معرفی کوتاه برند (در صورت وجود).
- **قاعده:** این صفحه نباید برای هیچ کلمه کلیدی تراکنشی (مثل «دانلود آهنگ جدید») بهینه شود؛ انکرهای ورودی آن فقط «درباره ما / درباره آهنگ بان» باشند.

## داده ساختاریافته

- `AboutPage` برای همین URL + `BreadcrumbList` (خانه ← درباره ما).
- `Organization` (یا `WebSite` موجود قالب) فقط با داده واقعی و قابل مشاهده: `name: آهنگ بان`، `alternateName: AhangBan`، `url: https://ahangban.ir/`. نشانی لوگو، ایمیل، شبکه اجتماعی یا نشانی پستی که روی سایت نیست وارد اسکیما نشود.
- هیچ `Review`، امتیاز، تاریخ تأسیس یا تعداد کاربر ساختگی افزوده نشود. اگر سال آغاز فعالیت را می‌خواهید بنویسید، فقط با عددی که خودتان تأیید می‌کنید.

## اصلاح همراه: صفحه تماس

عنوان فعلی «تماس باما» باید به «تماس با ما» اصلاح شود. متن کوتاه آماده برای بالای فرم تماس:

```text
برای پیشنهاد همکاری، فرستادن اطلاعات اثر، اصلاح اطلاعات یک اثر یا گزارش درباره اثری که در آهنگ بان منتشر شده است، از فرم زیر بنویسید. موضوع پیام را روشن انتخاب کنید تا پیامتان به بررسی درست برسد؛ ثبت پیام به‌معنای انتشار قطعی یا پاسخ فوری نیست.
```

## کنترل کیفیت این صفحه

- آیا موجودیت برند در پاراگراف اول، مستقل و روشن تعریف شده است؟ ✓
- آیا ادعای اثبات‌نشده (بزرگ‌ترین، کامل‌ترین، رسمی، همه آهنگ‌ها) وجود دارد؟ ندارد ✓
- آیا فقط به صفحاتی لینک شده که روی سایت زنده‌اند؟ ✓ (آرشیو کامل خواننده‌ها مشروط و جدا علامت خورده است)
- آیا مسیر تماس واقعی (`/contact/`) است و ایمیل/شبکه اجتماعی ساختگی ساخته نشده است؟ ✓
- آیا متن برای انتشار مستقیم آماده است؟ ✓
